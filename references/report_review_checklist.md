# 分析报告内容审核清单

在 `validate_analysis_report.py` 通过后、向用户交付前执行。审核对象必须来自同一输出目录：报告、manifest、质量报告、逐日明细、逐日分组汇总和信号文件。

## 1. 数据和窗口

- 报告的请求区间、有效区间、交易日数、ETF数量、观察池版本与 manifest/质量报告一致。
- 请求结束日晚于最新披露日时，报告明确区分请求结束日和有效结束日。
- 份额、价格、资金流覆盖率和缺失数量与质量报告一致；`partial` 数据没有写成完整覆盖。
- 报告没有引用输出目录之外的旧文件或旧报告数字。

## 2. 数字和排序

- 累计流量、分组流量、主要ETF贡献、最大流入/流出日和月度极值能在CSV或信号文件中复核。
- 日度流入榜只含严格大于零的记录，流出榜只含严格小于零的记录；月度榜同理。
- 未完成月份标注“截至某日”或“样本不完整”，不与完整月份直接比较。
- 报告中没有 `?`、`待补`、`TODO`、示例数字或旧口径残留。

## 3. 指标口径

- 分组比较使用加权资金流率：分组估算资金流合计 ÷ 分组估算期初资产合计；没有把各ETF百分比简单相加。
- 若使用“累计流量 ÷ 平均日资产”，必须明确写成累计流量相对平均日资产的倍数或强度，不能直接叫普通资金流率。
- 正流比例明确分母是全部观测记录还是非零申赎记录。
- 不同资产类别没有合计成一个“总资金流”；辅助资产只用于辅助说明。

## 4. 结论强度

- 每个主要结论都有事实数字、解释和限制；解释没有超过数据能支持的范围。
- “结构性切换”“资金转移”“主力买入”等强措辞只有在组间方向、广度、持续性或集中度有多项证据时使用；否则改为“结构性分化”“承接候选”或“弱信号”。
- 单只ETF或单只产品分组不被描述为“全组同步”；单日跳变不被自动描述为主力进场或撤退。
- 四象限只描述价格与份额的同日关系，不写成投资者动机或因果结论。
- 报告同时解释流入和流出，并说明极值前后5日是延续、反转还是无法判断。

## 5. 图表和文件交付

- 需要图表时，图表已用 Markdown 图片语法嵌入报告，使用相对报告目录的路径，并有中文替代文字；只放PNG普通链接不算完成。
- 不需要图表时，报告不提“图表/下图”，也不留下PNG链接。
- 逐日明细、逐日分组汇总、质量报告和信号文件均与报告位于同一输出目录，链接或文件名没有指向旧目录。

## 审核结果

只有所有适用项通过，才可把报告交付给用户。若某项因样本不足无法判断，应在报告中明确写“本样本无法判断”，并说明原因。
