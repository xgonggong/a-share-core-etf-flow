# 数据挖掘与叙事方法

这份参考只在生成分析报告时读取。目标是从实际数据中找出可复核的资金行为线索，而不是把模板字段逐项填满。

## 推荐派生指标

对每个交易日、ETF和分组计算：

- `flow_yuan` 或亿元估算净申购赎回；
- `share_change_rate = share_change / previous_shares`；
- `relative_flow = flow / (previous_shares × previous_close)`；分组层使用“累计流量 ÷ 日均估算期初资产”作为相对规模指标，并明确它是窗口累计强度，不是单日收益率；
- 分组日/月资金流率必须使用“分组估算资金流合计 ÷ 分组估算期初资产合计”，不能把各只 ETF 的百分比简单相加；
- 当日正流ETF数、负流ETF数、同向比例和组内中位数流量率；
- 5日、20日滚动累计流量及连续流入/流出长度；
- 单只ETF对组内净流量的贡献率，以及组内流量的集中度；
- 价格变化与份额变化的四象限状态；
- 相对过去20个有效交易日的分位数或滚动中位数/MAD异常分数。

金额用于识别影响最大的产品，相对流量用于避免大基金天然占优。两者不一致时必须同时报告，例如“绝对金额最大，但相对规模并不异常”。

资金广度和集中度只有在分组含至少两只有效 ETF 时才有比较意义。单只产品分组的广度100%或集中度100%只是数学结果，不能作为同步性或集中度证据。

## 如何筛选真正有用的发现

先从全样本扫描，而不是从用户提到的事件日期倒推结论：

1. 按日排序，取资金广度最高的流入日和流出日；
2. 按分组计算滚动流量和组间流量差，查找方向切换；
3. 按ETF计算贡献率、异常分位数和异常后的5日延续/反转；
4. 按价格—份额象限统计各组占比，判断追涨、逢跌配置或兑现；
5. 对每个候选结论至少找两项独立证据：例如金额+同步性、份额率+持续性、价格象限+后续方向。

对于达到60个交易日的窗口，必须额外计算核心股票及主要分组的日度流入/流出前5名、月度流入/流出前3名。对日度第一名查看此前5个和此后5个交易日，并披露当日同向ETF数量、主要贡献品种及 `tech_flag`。先判断累计结果是否由少数月份或少数日期主导，再决定能否使用“持续流入/流出”这样的措辞。

只有满足“证据充分、不是单日偶然、能解释组间或品种差异”的候选才写入数据发现卡。最终只保留 3～4 张最有用的卡；其余候选放入附表或舍弃。若只满足一项，应标为“弱信号”或放入限制部分。

## 叙事句式

报告写作顺序固定为：先说判断，再给证据，最后给限制。每张发现卡建议控制在一个短段落或三行以内，避免把同一结论拆成多段。数字只保留能改变判断的数字；其余指标放表格。

每个发现按三层写：

> **事实**：在日期/区间内，某组或某ETF出现了什么，数值是多少。
>
> **解释**：这更像新增配置、逢跌配置、兑现、风险收缩、风格轮动，还是单只产品调仓。
>
> **限制**：份额变化无法识别投资者身份；价格替代NAV；技术异常、跨境或样本覆盖可能改变解释。

避免“资金明显看好”“主力大举进场”等没有证据强度的词。用“配置候选”“与……一致”“弱信号”“未发现稳定证据”等表述。

报告的总判断应尽量落在以下三种之一：

- **整体增配**：实际纳入的核心组多数同向、资金广度较高且持续；
- **结构性切换**：实际纳入的核心组之间方向相反，且相对规模流量和多只产品同步支持；
- **分化或无法判断**：方向混杂、集中在单只产品，或持续性和数据质量不足。

不要把“黄金和国债也流入”单独升级为“股票避险”结论；只有当股票核心组出现同步流出，并且辅助资产方向持续一致时，才可写成“与防御配置相一致的辅助信号”。

## 最低可交付的研究判断

- 日度、月度流入榜只从严格大于 0 的记录中取前几名，流出榜只从严格小于 0 的记录中取前几名；如果窗口内没有负流量，报告应明确写“样本期未出现净流出”，不能把最小的正数当成流出。

报告必须用简短段落明确回答以下问题：

- 样本期核心股票ETF是整体同向，还是组间分化？
- 最大买入和最大卖出是广泛同步，还是由一只ETF主导？
- 流入/流出是否持续，异常日之后有没有反转？
- 价格下跌时是否仍有增份额，或者上涨时是否出现减份额？
- 哪个结论证据最强，哪个只是弱信号？
- 最大流入、最大流出发生在何时，之后是延续还是反转？累计结果是否集中在少数月份？

如果数据不足以回答，直接写“本样本无法判断”，并指出缺口。
